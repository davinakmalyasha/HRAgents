# AI Engineer Evaluation Rubric

## Technical depth

Focus on what was actually built: retrieval systems, agent pipelines, fine-tuning,
evaluation harnesses, inference optimization. Conference papers, blog posts, and open
source contributions are evidence; course certificates alone are not.

## Stack alignment

Python ecosystem depth (not just "Python" listed): frameworks used in context —
PydanticAI, LangChain, PyTorch, vLLM, vector databases. Check dependency manifests in
repositories where available.

## Systems literacy

LLM systems fail in production for operational reasons: token budgets, latency,
caching, evaluation regressions, drift. Look for evidence the candidate has operated
these systems, not just prototyped them.

## Verifiable certifications

Cloud ML certifications with verifiable IDs (AWS ML, GCP ML) and publication records
with DOIs. Prompt-engineering certificates and unverifiable badges carry minimal weight.
