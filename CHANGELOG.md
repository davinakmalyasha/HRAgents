# Changelog

All notable changes to this project are documented here. The format follows
[Keep a Changelog](https://keepachangelog.com/en/1.1.0/) and the project adheres to
[Semantic Versioning](https://semver.org/spec/v2.0.0.html).

Releases are prepared automatically by [release-please](https://github.com/googleapis/release-please):
merge the release PR to bump the version, tag, and publish. See
[`docs/plan/release-process.md`](docs/plan/release-process.md).
